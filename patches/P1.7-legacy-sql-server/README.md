# بسته قابل‌انتقال P1.7 — اتصال و مهاجرت فقط‌خواندنی دیتابیس‌های قدیمی (Legacy SQL Server)

## ۱. هدف و ارزش ماژول
خواندن امن و بدون تغییر (فقط‌خواندنی / Dry-Run) از دیتابیس‌های قدیمی کلینیک روی سرور ncase3:
۱. `dam2000`: پرونده‌ها، سوابق واکسیناسیون و مراجعات قبلی
۲. `Parsian1405`: اسناد مالی، فاکتورها، اشخاص و انبارداری پارسیان

## ۲. ساختار فایل‌ها
- `source/legacyDatabaseService.ts`: متادیتا و سرویس نگاشت فیلدهای دیتابیس‌های قدیمی
- `source/LegacyDatabasesConnectorPanel.tsx`: کامپوننت بررسی کانکشن و پیش‌نمایش جدول‌ها
- `source/Connect-LegacyDatabases.ps1`: اسکریپت پاورشل بررسی ارتباط شبکه‌ای OLEDB/ODBC در سرور محلی
- `server_endpoints.diff`: تغییرات روت‌های سرور `/api/legacy-db/*` و `/api/legacy/sql/*`
- `env.example`: متغیرهای هاست و نام کاتالوگ
- `tests/acceptance_test.ts`: آزمون پذیرش بررسی اسکریپت پاورشل و دریافت اسکیمای فقط‌خواندنی

## ۳. قواعد امنیتی (Iron Rule)
- این بسته کاملاً فقط‌خواندنی (Read-Only) است و تحت هیچ شرایطی نباید داده‌ای در دیتابیس‌های مبدأ دستکاری شود.
- اجرای اسکریپت با روش شبیه‌سازی و بررسی کاتالوگ (Dry-Run) صورت می‌گیرد.

## ۴. آزمون پذیرش (Acceptance Test)
```bash
npx tsx patches/P1.7-legacy-sql-server/tests/acceptance_test.ts
```
نتیجه: تأیید سلامت اسکریپت پاورشل و استخراج متادیتای ۴ جدول dam2000 و ۴ جدول Parsian1405.
