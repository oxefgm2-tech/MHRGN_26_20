# بسته قابل‌انتقال N2 — پل همگام‌سازی ربات بله ↔ هسته کلینیک (Bale Bot Sync Bridge)

## ۱. هدف و ارزش ماژول
این سرویس وظیفه تبدیل و قالب‌بندی اطلاعات پروفایل کلینیک، ساعات کاری، منوهای تعاملی و پیلودهای نوبت‌دهی را به ساختار استاندارد مورد انتظار ربات بله (`clinic_info.json`، `working_hours.json`، `menu.json`) بر عهده دارد.

## ۲. پیش‌نیازها و ریسک‌ها
> ⚠️ **وابستگی الزامی:** این بسته وابسته به **P1.1 (ربات بله)** و به توکن **`BALE_BOT_TOKEN`** است.
این سرویس فقط کلاینت‌ساید / سرویس‌به‌سرویس (Client-side / Service-to-Service Transformer) است و مستقیماً منطق داده‌ای پروفایل کلینیک را با فایل‌های پیکربندی ربات همگام می‌سازد.

## ۳. ساختار فایل‌ها
- `source/baleBotSyncService.ts`: سرویس تبدیل داده‌های کلینیک به ساختار پیکربندی ربات بله
- `server_endpoints.diff`: مستندات روت سروری (این سرویس کلاینت‌ساید است)
- `dependencies.json`: وابستگی‌ها و قید `requires: ["P1.1-bale-bot"]`
- `env.example`: متغیرهای محیطی ربات بله
- `tests/acceptance_test.ts`: آزمون صحت تایپ‌ها و تولید ساختارهای JSON

## ۴. آزمون پذیرش (Acceptance Test)
```bash
npx tsx patches/N2-bale-sync/tests/acceptance_test.ts
```
