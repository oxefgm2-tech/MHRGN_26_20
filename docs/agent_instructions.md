# راهنمای ایجنت‌ها (دستیارها)

- تمرکز اصلی: پاسخ‌ها باید بر مبنای داده‌های seed و داشبورد متمرکز بر پت باشند.
- وقتی کاربر دربارهٔ پیشنهاد رسانه برای یک پت پرسید:
  - از pet.breed, appearance_tags و description استفاده کنید.
  - عبارات جستجوی پیشنهادی برای YouTube مثال:
    - "playful <breed> frisbee"
    - "<breed> relaxation sounds rain birds"
    - "<breed> grooming tips"
- دربارهٔ تولید soundscape:
  - گزینه‌ها: آمبینت (باران + پرنده)، سمپل‌های جلب توجه (صداهای کوتاه همنوع)، و خروجی MP3 قابل دانلود.
  - پیشنهاد کنید: "Render offline on server" و محل ذخیره و نحوهٔ پخش را توضیح دهید.
- درخواست‌های دسترسی:
  - نقش‌ها را به بازدیدکنندهٔ ناشناس نشان ندهید.
  - مدالی باز شود: "درخواست دسترسی بدهید — شرح نقشتان را بنویسید" و درخواست به مدیران ارسال شود.
- هر متن حقوقی یا قرارداد باید توسط مدیران بارگذاری و تایید شود.
